# Research that supports decisions

Start with what the source can establish. Then explain what we should do with it.

The [weekly intake baseline](intake/reports/baseline.md) preserves the full supplied collection as individually scored items. This research-note register is a smaller selected reference set; it is not the whole intake. Use [the complete ledger](intake/events.json) for original item analysis, sources, CTSS inputs, and follow-up decisions.

[Evidence register](evidence.json) stores short, reusable records. Each has a source, version, review depth, finding, limitation, CSF link, and decision. Sources describing the same study share a lineage ID and count once. A new version updates the interpretation but does not become a second independent study. Keep superseded records when a finding changes.

## Add one useful record

Use an official paper or direct record where possible. Record the publication date separately from the date reviewed. Say whether we read an abstract, full paper, code, or reproduced an experiment. List the tested population or system when known. State what would change our recommendation. Keep model capability, delivery, human exposure, behavior change, persistence, and recovery separate.

The November 7 intake was checked against primary source abstracts and the Anthropic research page. It was not a full systematic review or independent reproduction. The register is a maintained working record, not a complete literature database. Earlier weekly briefs remain background material; incident and legal claims need their underlying sources reviewed before reuse as established facts.

Do not add another score for research popularity. Strong contrary evidence belongs in the record. Helpful assistance, justified agreement, and evidence-based belief revision can all preserve agency.
