# Watch and action register

Every imported excerpt has a stable ID, original source locator, disposition, responsible role, next review, and status history. Some excerpts are headings or indicators, so 217 excerpts do not mean 217 independent incidents or implementation projects. Named assignees remain unassigned; roles are proposed responsibilities.

| Status | Count | Meaning |
|---|---|---|
| deferred | 5 | Explicit decision to retain the question without changing the core scoring method |
| documented | 45 | Written guidance exists; field implementation/validation remains open |
| needs_research | 37 | A study or investigation is needed |
| reference | 6 | A grouping label, not an independent task |
| watching | 124 | Await a relevant observation; review weekly |

## How to use it

The searchable [research hub](../../../docs/research.html#signals) reads this same register. Use [CSV](register.csv) or [JSON](register.json) for tracking. Review items marked review_first, due items, new evidence, and repeated themes. An item cannot be closed without a reason and evidence. Documented does not mean deployed or effective.

Run `python -m tools.signals check` to validate it. To update an item, use `python -m tools.signals update --id SIGNAL_ID --status STATUS --note "Reason" --evidence path/to/evidence.md --review-on YYYY-MM-DD`. This appends history and rebuilds the register views. Ownership changes must reflect actual assignment, not inferred participation.
