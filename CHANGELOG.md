## v3.0.0: research-to-control framework update

The owner designated this work as CSF v3.0.0. It expands research intake, domain controls, readiness assessment, public documentation, and agent access. The six domains, five causal layers, and CTSS weights remain unchanged. [CSF 3.0 is published](https://github.com/CyberStrategyInstitute/cognitive-sovereignty/releases/tag/Cognitive_Sovereignty_Framework-v3.0), and its documentation site is deployed from main/docs.

- Correct reference-score arithmetic, preserve prior values, and generate consistent totals for the calculator and dashboards.
- Add the complete supplied weekly intake as 87 provisional item records, original analysis, seven research reports, source lineage, revisions, and cohort trends.
- Track all 217 source signals with stable IDs, statuses, proposed responsibility, review triggers, and history.
- Add practical and advanced checks, four research notes, a declared baseline/lens assessment, and data-only lens prototypes.
- Add a shared visual style and navigation, a searchable research hub, and a keyboard-operable live scorecard based on the attached template.
- Add a data catalog, schemas, read-only query tools, agent guidance, and an optional local MCP adapter.
- Add validation, contributor templates, corrected code ownership, pinned CI actions, and documented review boundaries.

The inherited CTSS method remains an assessed prioritization method. Provisional event scores, reference estimates, observations, and illustrative lenses stay separate. Broader field effectiveness and full source re-verification remain ongoing research.

## Version consistency and upgrade

`VERSION` defines 3.0.0. Builds apply that version to all website page titles, navigation labels, and page metadata. The citation, current framework documentation, registry, and data catalog use the same version and are checked in CI. Historical source versions, schema versions, lens profiles, method IDs, and prior assessment records keep their own identities.

Existing threat IDs and mitigation IDs remain usable. Use the revised catalog revision when testing the 20 refined controls. Keep the 12 new readiness-extension checks separate from inherited capability totals. Begin a new comparison when criteria change; do not relabel old outcomes as 3.0 observations.
